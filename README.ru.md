# ESPidi HUB

**Загрузочное меню для платформы [ESPidi](https://github.com/EugeneCarlo/ESPidi): две прошивки на одной плате, выбор при включении.**

ESPidi HUB — небольшой загрузчик и лаунчер для платы ESPidi на ESP32-C3 Super Mini. Он хранит две прошивки — например, [RED SEA](https://github.com/Cirocular-Vlasenko-Daniil/Red-Sea) и ещё одну — и при каждом включении запускает одну из них. Прошивки остаются обычными сборками Arduino или ESP-IDF; где они лежат во флеше, решает HUB.

English version: [README.md](README.md).

## При включении

| Зажать | Запустится |
|---|---|
| PLAY | слот 1 |
| PAGE | слот 2 |
| ничего | прошивка, работавшая в прошлый раз |
| кнопку энкодера | меню HUB (установленные прошивки, свободное место) |

Нажимайте во время короткой заставки, когда экран уже загорелся. Пока прошивка запускается, HUB показывает её **обложку** — картинку 64×32 — с именем и версией. Перезапуск изнутри прошивки возвращает ту же прошивку, выключение-включение или кнопка RESET — HUB.

## Размер прошивок

Фиксированных размеров у слотов нет. Слот 1 растёт от одного края области прошивок, слот 2 — от другого, поэтому установщик даёт каждой прошивке ровно столько места, сколько ей нужно, и проверяет остаток: до **2,62 МБ** для одной прошивки или сколько осталось рядом со второй. Установка в один слот никогда не двигает и не трогает другой.

Все прошивки делят 16 КБ под настройки (NVS) и раздел LittleFS на 1 МБ под файлы — каждая в своём пространстве имён и своей папке.

## Сборщик (сайт)

**[espidi-hub.github.io](https://espidi-hub.github.io/)** — выберите прошивку для каждого слота из каталога, **вставьте GitHub-репозиторий** по SDK (`owner/repo` — прошивка, обложка и описание берутся прямо оттуда) или загрузите свой `.bin`, задайте обложку (родную или любую картинку — 64×32 и кратные идут пиксель в пиксель, остальное уменьшается с дизерингом), посмотрите, как поделится память и что покажет HUB, а затем:

- **запишите в ESPidi по USB** прямо из браузера (Chrome, Edge или Opera на компьютере): полная установка или обновление слотов с сохранением настроек и файлов;
- или **скачайте один образ** для чистой установки любым прошивальщиком (`esptool --chip esp32c3 write_flash 0x0 espidi-custom.bin`).

Исходники сайта — в `web/`; его логика — перенос установщика ниже, и она сверяется с ним байт в байт (`web/test.html`).

## Установка из командной строки

Нужны Python 3 и `pip install esptool`:

```bash
# один раз: стирает флеш, пишет загрузчик и HUB (скачиваются из последнего релиза)
python3 tools/espidi_hub.py base -p /dev/cu.usbmodem1101

# прошивки в слоты
python3 tools/espidi_hub.py install -p /dev/cu.usbmodem1101 --slot 1 REDSEA.ino.bin
python3 tools/espidi_hub.py install -p /dev/cu.usbmodem1101 --slot 2 other.bin --cover other.png
python3 tools/espidi_hub.py install -p /dev/cu.usbmodem1101 --slot 2 owner/repo   # репозиторий по SDK

# что установлено
python3 tools/espidi_hub.py info -p /dev/cu.usbmodem1101
```

`install` берёт обложку, встроенную в прошивку, если не указаны `--cover` (PNG/PBM, 64×32 или кратная) или `--no-cover`. `base` — единственная команда, которая стирает настройки. `image --hub-dir <папка> --slot1 a.bin --slot2 b.bin --out custom.bin` собирает тот же единый образ, что и сайт.

## Разработка прошивок

- [docs/FIRMWARE_GUIDE.ru.md](docs/FIRMWARE_GUIDE.ru.md) — правила, распиновка, хранение данных, размер, сборка, публикация ([in English](docs/FIRMWARE_GUIDE.md)).
- [AGENTS.md](AGENTS.md) — те же правила в виде чек-листа для ИИ-агентов.
- `sdk/ESPidiHub` — библиотека Arduino: распиновка, дескриптор `ESPIDI_FIRMWARE()`, `ESPIDI_COVER()`, безопасная работа с файлами, `rebootToHub()`. Обложки: [sdk/ESPidiHub/COVERS.ru.md](sdk/ESPidiHub/COVERS.ru.md).
- `sdk/ESPidiPad` — M-VAVE SMC-PAD Pro по Bluetooth как контроллер: события, RGB-пэды, общее сопряжение ([README](sdk/ESPidiPad/README.ru.md)); основа — кит SMC-PAD Pro по BLE Руслана Мазавина.
- `templates/arduino-firmware` — готовый репозиторий по SDK для копирования: скетч, `espidi.json`, `cover.png` и workflow для GitHub Actions, который собирает, проверяет и публикует `.bin`, чтобы сборщик ставил прошивку по ссылке.

## Репозиторий

| Путь | Что |
|---|---|
| `hub/` | проект ESP-IDF: приложение HUB и свой загрузчик |
| `tools/espidi_hub.py` | установщик (размеры слотов, таблица разделов, метаданные) |
| `web/` | сайт-сборщик: `espidi.js` (перенос установщика), `app.js`, каталог прошивок |
| `sdk/`, `templates/` | для авторов прошивок |
| `docs/ARCHITECTURE.md` | загрузка, разметка флеша, бинарные форматы |

HUB и загрузчик собирает GitHub Actions на ESP-IDF v5.5; версии с тегом публикуют `bootloader.bin`, `espidi_hub.bin` и установщик в релиз.
